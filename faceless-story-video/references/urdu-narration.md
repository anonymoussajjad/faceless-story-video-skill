# Urdu narration rules

## Script (the rule that matters most)

- Urdu narration is written ONLY in Urdu script (the Arabic-based Urdu alphabet).
- NEVER write Urdu narration in Devanagari (Hindi) script — no Hindi letters at all.
- NEVER write Roman Urdu when the language is `ur`. Roman Urdu is a different output (Pro version) — in Lite, `ur` means Urdu script, `en` means English.
- English words inside Urdu narration (e.g. "school", "mobile") are fine in Roman letters only when people actually say them that way; keep them rare.

## Voice and tone

- Natural spoken Urdu, as a kind elder tells a story: short sentences, warm tone, no formal/poetic Urdu.
- One speaker only — the narrator. Characters never talk to each other inside one clip. If a scene needs two people speaking, split it into two one-speaker clips.
- Every scene has narration. A scene with no narration is a silent scene, and a silent scene is a failure, not a style choice.

## Pronunciation notes (for the voiceover, not the script)

Urdu is normally written without diacritics, and small text-to-speech voices read words as written — so a few common words come out wrong unless their spelling carries the sound:

- **Shadda (ّ) = the sound doubles.** The classic fix: کتے reads "kutay" but کُتّے reads "kuttay". Same pattern: بچہ → بچّہ, بلی → بِلّی, اچھی → اَچھّی, مکھی → مَکّھی.
- **First-syllable vowel (zabar/zer/pesh) fixes the vowel:** گھر → گَھر ("ghar"), تتلی → تِتلی ("titli"), پھل → پَھل ("phal"), چکھا → چَکھا ("chakha"), ڈری → ڈَری ("dari").
- **Never put a vowel mark before و or ی unless the word truly has that long vowel** — a mark there changes the vowel itself (بولا with a pesh becomes "boola", کو becomes "koo"). When in doubt, leave the word plain.
- **فوراً is written فوراً, not فورن** — with the tanwin it reads "fauran" (immediately); without it, voices say "foran".

When writing a script for a real voice tool, add these spellings only to the words that need them. Do not sprinkle diacritics on every word — plain Urdu is the default, and over-marking creates new mistakes.

## Words that need care in stories

- گھر (ghar), مکھی / مکھیاں / مکھیوں (makkhi — bee/fly), ننہی (nanhi — tiny), ڈری (dari — she got scared), فوراً (fauran — immediately), چکھا (chakha — tasted), اچھی (achchhi — good), تتلیاں (titliyan — butterflies), پھل (phal — fruit).
- Keep narration sentences short so the voice never rushes: one idea per sentence, and a pause (comma or full stop) before the emotional line.
